# CourseAtlas · 南开选课导航

> 高校模拟排课与学分路径规划器 —— 让每一分都花在刀刃上。

《前端开发实训》期末工程项目（Web 方向）· Vue 3 + Vite + TypeScript

## 项目背景

选课周前，每个大学生都会遇到三个问题：**这门课和已选的课冲不冲突？它到底怎么样？离毕业要求还差几个学分？** 教务系统只负责"抢课"，不负责"规划"，课程质量也全靠口口相传。CourseAtlas 用南开大学教务部公开的**真实选课手册数据**（两个学期、9000+ 教学班）加上学生真实课程评价，把选课决策一次做完整：模拟排课、冲突拦截、课程评价、学分规划、历史学期查询。

**目标用户**：南开大学等高校在校本科生，尤其是每学期需要自主选课的低年级学生。

## 功能列表

- **学期选择（学年 × 三学期）**：仿教务系统设计——点顶部学期按钮弹出学年面板（2020-2021 起连续排列至 2026-2027），每学年含 1=秋冬、2=春夏、3=暑假小学期；已导入公开数据的学期标注教学班数，未公开的标注"无数据"（仍可选中用于记录/手工录课）。切换后课程库、课表、统计相互独立，历史学期记录长期保留。
- **课程库（真实数据）**：2026 秋 4876 个教学班（3510 门课，69 个开课单位），支持关键词搜索（课程名/课程号/教师/教室）、开课单位筛选、课程类别筛选、通识六模块筛选、按名称/单位/名额排序、分页浏览；加载中有骨架屏，失败可重试。
- **课程评价**：详情弹窗展示来自《枝上 26 秋选课攻略》的学生真实评价（评分制、点名习惯、给分、平时任务、期末考核，共 644 条，覆盖 592 个课程名）。
- **模拟课表**：周一至周日 × 1-14 节网格视图，移动端切换按天列表；加入课程时自动拦截时间冲突（同天 + 节次重叠 + 周次有交集，支持单双周），重叠课程红色虚线标注。
- **学分录入与规划**：选课手册不含学分，学分为你在课表页按本人培养方案录入（0.5 步进）；规划页区分"已录学分 / 待补学分"，按类别展示培养方案进度（示例配置，可替换为本专业要求），并汇总全部学期。
- **自定义课程**：课程库之外的教学班（校外/重修/实验等）可录入，含完整表单校验（必填、长度、学分范围、节次与周次先后关系）与时间冲突检测，提交到当前学期。
- **数据持久化**：选课记录按学期存储于 localStorage，刷新/重开不丢失。
- **响应式**：桌面（顶部导航 + 网格课表 + 双栏布局）与手机（底部标签栏 + 列表课表）双端适配。

## 页面结构（路由）

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/courses` | 课程库 | 真实课程搜索 / 筛选 / 排序 / 分页 / 评价弹窗 / 加入课表 |
| `/timetable` | 模拟课表 | 7 天 × 14 节网格 + 冲突高亮 + 学分录入 + 已选管理 |
| `/planner` | 学分规划 | 示例培养方案进度、当前/历史学期记录、分类明细 |
| `/custom` | 自定义课程 | 表单校验 + 冲突检测 + 提交入表 |

## 技术栈

- Vue 3（组合式 API + `<script setup>`）、TypeScript（strict）
- Vite 8、Vue Router 4（懒加载路由 + 路由级标题）、Pinia 3（学期 / 课程库 / 选课计划三个 store）
- 自研轻量设计系统（CSS 变量，主色取南开青莲紫 `#842468`，取自教务部官方标识实取样），未引入第三方 UI 框架
- 数据层：按学期懒加载的 JSON 静态数据（`public/data/`），fetch + 骨架屏 + 错误重试
- ESLint 9 + Prettier 3 代码规范；playwright-core 端到端冒烟测试

## 数据来源与口径

| 数据 | 来源 | 口径 |
| --- | --- | --- |
| 2026 秋课程（4876 教学班） | 南开大学教务部《2026-2027 学年第一学期选课手册》公开 PDF，脚本解析 | 课程名、教师、星期/节次/周次、教室、名额为**真实排课信息**；停课记录未导出 |
| 2025 春课程（4525 教学班） | 教务部《2024-2025 学年第二学期选课手册》公开 PDF | 同上 |
| 课程评价（644 条） | 《枝上 26 秋选课攻略》（学生填写整理） | 原样摘录学生评价；与课程按课程名匹配（406 条评价命中 2026 秋课程名） |
| 学分 | **无公开数据** | 手册与攻略均不含学分，由用户在计划中按本人培养方案录入，不做任何虚构 |
| 毕业学分要求 | **示例配置** | 南开未公开全量培养方案，`src/constants.ts` 中 REQUIREMENTS 为演示值，可按本专业方案修改 |

解析与导出脚本见 `data-nankai/`（`parse_handbook.py` 解析、`validate_courses.py` 校对、`export_app_data.py` 生成应用数据），采集过程与校验记录见 `docs/05-南开真实课程数据采集.md`。

## 环境要求

> 本项目使用 **Vite 8** 与 **TypeScript 6**，请确保本地 Node.js 版本满足要求（Node.js 18 及以下不兼容 Vite 8）。

- **Node.js**：`>= 20.19.0`（推荐 **22 LTS / 24.x**；项目在 `Node.js v24.21.0` + `npm 11.x` 环境实测通过）
- **包管理器**：`npm >= 10`
- **浏览器**：Chrome / Edge / Firefox / Safari 等现代浏览器（`npm run smoke` 需本机安装 Chrome 或 Edge）
- **操作系统**：Windows / macOS / Linux 均可（项目内无本机绝对路径依赖）

## 已知问题

1. 纯前端应用，数据为构建时生成的静态 JSON，未接入教务实时接口。
2. 学分数据缺失是南开公开资料的客观限制：所有课程学分需用户自行录入，未录入的课程不计入规划统计（页面有明确提示）。
3. 培养方案要求为示例配置，未覆盖各专业真实要求。
4. 课程评价按课程名匹配，个别改名课程可能匹配不到；评价仅覆盖 2026 秋。
5. 时间冲突按"周次有交集即冲突"判定，未区分同一门课不同教师/教室的调课例外。
6. 学期面板按 2020-2021 至 2026-2027 连续列出（每学年三学期），但教务部目前只公开了两个学期的选课手册（2026-2027-1、2024-2025-2），其余学期标注"无数据"；需要时把新手册放进 `data-nankai/` 后运行导出脚本并在 `TERM_DATA_INFO` 登记即可。
