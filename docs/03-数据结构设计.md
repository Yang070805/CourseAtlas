# 03 · 数据结构设计

> 版本 v1.0 ｜ 2026-11-26 ｜ 对应阶段：需求与原型

## 1. 核心类型（src/types/index.ts）

```ts
type CourseCategory = '通识必修' | '通识选修' | '学科基础' | '专业必修' | '专业选修' | '实践环节'

interface CourseSlot {
  day: number        // 1-5：周一 ~ 周五
  start: number      // 起始节次 1-12
  end: number        // 结束节次（含）
  weeks: number[]    // 上课周次列表，如 [1..16]
}

interface Course {
  id: string                 // 稳定标识（课程库：语义 id；自定义：custom-时间戳）
  code: string               // 课程编码
  name: string
  college: string            // 开课学院
  category: CourseCategory
  credit: number             // 学分（允许 0.5 步进）
  hours: number              // 总学时
  assessment: '考试' | '考查'
  semester: number           // 开课学期 1-8
  teacher: string
  slots: CourseSlot[]        // 一个或多个上课时间段；空数组 = 分散安排
  prerequisites: string[]    // 前置课程 id 列表
  description: string
}

interface SelectedCourse {
  id: string
  course: Course
  source: 'catalog' | 'custom'
  addedAt: number            // 加入时间戳（排序与展示）
}

interface RequirementItem {
  category: CourseCategory | '总计'
  label: string
  min: number                // 最低学分
  note?: string
}

type AddResult =
  | { ok: true }
  | { ok: false; reason: 'duplicate' | 'conflict' | 'credit-cap'; ... }
```

| 专业必修 | 44 | 专业基础课与专业核心课 |
| 专业选修 | 24 | 含跨专业选修不低于 6 学分 |

其他常量：学期学分上限 `SEMESTER_CREDIT_CAP = 30`；`PERIOD_TIMES`（12 节时间轴）；`CATEGORY_STYLE`（类别配色）。

## 3. 课程库 Mock 数据（src/data/courses.ts）

- 共 **79 门**课程，覆盖 8 个学期、10 个开课学院、6 个课程类别。
- **蓝本与虚构声明（诚信说明）**：课程目录（课程编码 / 名称 / 属性 / 学分 / 学时 / 开课学期）依据长沙理工大学计算机学院公开的《软件工程专业培养方案(2026)》课程体系表整理（链接见 README）；**上课时间段、周次、授课教师、前置课程关系均为本项目虚构的演示数据**，不对应任何真实教学安排。
- 刻意构造的演示冲突：第 2 学期《高等数学A（二）》与《大学物理B（上）》同为周一 3-4 节、1-16 周，用于展示冲突拦截。
- 前置课程示例：《数据结构》→《计算机程序设计》；《算法分析与设计》《操作系统》→《数据结构》；《深度学习》→《机器学习及应用》；《机器学习及应用》→《概率论与数理统计》《线性代数》；《毕业设计》→《软件工程》。

## 4. 持久化设计（localStorage）

- 键名：`course-atlas:selected-courses:v1`（带版本号，未来结构变更可平滑迁移）
- 内容：`SelectedCourse[]` 的 JSON；自定义课程随 selected 一并持久化
- 写入时机：加入 / 移除 / 清空操作后立即同步写入；启动时读取，解析失败静默降级为空
- 已知边界：隐私模式下写入失败时降级为内存态，不影响功能

## 5. 状态设计（Pinia）

| Store | 状态 | 派生（getters） | 动作 |
| --- | --- | --- | --- |
| courses | 课程库、关键词、学院 / 类别筛选、排序、页码 | 学院列表、过滤 / 排序 / 分页结果、总页数 | 设置关键词 / 切换筛选 / 设置排序 / 翻页 / 重置 |
| planner | 已选课程（含持久化恢复） | 总学分、分类学分、学期分布、冲突对、前置缺失 | 加入（含三重校验）、移除、清空、判重 |

状态与业务校验的边界：冲突检测（`utils/conflict.ts`）与学分统计（`utils/credit.ts`）为纯函数，Store 只负责编排与持久化，保证算法可单测、可在答辩中独立讲解。
