# 03 · 数据结构设计

> 版本 v2.0 ｜ 2026-11-26 ｜ 对应阶段：核心功能开发（南开真实数据接入后修订）

## 1. 核心类型（src/types/index.ts）

```ts
type CourseCategory = '通识必修课' | '通识选修课' | '大类基础课' | '专业课程' | '其他课程'

interface CourseSlot {
  day: number      // 1-7：周一至周日
  start: number    // 起始节次 1-14
  end: number      // 结束节次（含）
  weeks: number[]  // 上课周次，如 [1..17]、[3,5,7..]（单双周即非连续数组）
}

/** 教学班 = 课程 + 一条开课记录（选课的最小单位） */
interface Offering {
  id: string            // 全局唯一（导出时顺序编号 C0001…）
  code: string          // 课程号（手册体系内唯一，跨单位可能重复）
  name: string
  unit: string          // 开课单位（69 个中出现课程数据的 38 个）
  category: CourseCategory
  typeLabel: string     // 细分类：体育/大学英语/思想政治/心理健康/军事理论/数学/计算机/专业课程/国际学生/创新创业/自定义课程
  module: string        // 通识六大模块或体育专项类别，其余为空
  teacher: string
  slots: CourseSlot[]   // 可为空（实践类课程不排固定节次）
  room: string
  capacity: number | null       // 选课名额（培养方案内）
  crossCapacity: number | null  // 跨专业名额
  sectionLabel: string  // 同课多班时「班次 1/3」，否则空
  remark: string        // 手册备注（组1/组2 等）
}

interface Review {      // 枝上学生评价
  category: string; teacher: string; grading: string
  attendance: string; score: string; review: string
  tasks: string; exam: string; unit: string
}

interface SelectedCourse {
  id: string            // `${termId}:${course.id}`
  termId: string
  course: Offering
  credit: number | null // 学分：手册未提供，用户录入；null = 待补
  source: 'catalog' | 'custom'
  addedAt: number
}

/** 学期：学年 + 学期号（1=秋冬、2=春夏、3=暑假小学期） */
interface Term {
  id: string            // 例：2026-2027-1
  academicYear: string  // 例：2026-2027
  semesterNo: 1 | 2 | 3
  label: string         // 例：2026-2027 学年第一学期（秋冬）
  shortLabel: string
  seasonLabel: '秋冬' | '春夏' | '暑假小学期'
  isCurrent: boolean    // 当前学期（数据与公告口径）
  hasData: boolean      // 是否已导入公开课程数据
  courseCount?: number  // 该学期教学班数
}
```

## 2. 数据管线（data-nankai/ → public/data/）

```
教务部选课手册 PDF（官方公开）
  └─ parse_handbook.py     → nankai_courses_2026秋.json / 2025春.json（逐行校验 0 异常，见 docs/05）
       └─ annotate_types.py → 增加 course_type / type_source 标注
            └─ export_app_data.py → public/data/term-2026-2027-1.json（4876 条）
                                    public/data/term-2024-2025-2.json（4525 条）
枝上 26秋 选课攻略 xlsx → export_app_data.py → public/data/reviews.json（644 条，按课程名索引）
```

- **停课记录不导出**：手册备注含"停课"的 40 条开课记录从应用中剔除（不可选）。
- 模块名清洗：PDF 折行产生的 `身体素质训 练` 等内部空格已去除。
- 名额语义遵循手册原文：`capacity`=培养方案内名额，`cross_capacity`=跨专业名额，通识选修课只有跨专业名额属正常。
- 应用侧数据体积：2026 秋 1.66 MB / 2025 春 1.53 MB / 评价 0.26 MB，按学期懒加载，失败可重试。

## 3. 学分口径（红线）

- **公开资料不含学分**：选课手册只有名额，枝上攻略亦无学分字段。项目**不虚构学分**。
- 学分由用户在"模拟课表 → 已选面板"按本人培养方案录入（0.5 步进，0.5-20），自定义课程在表单中必填。
- 未录入学分的课程标记"学分待补"，不计入任何学分统计；规划页、已选面板、头部徽章均给出待补数量。
- 培养方案要求（REQUIREMENTS）为**示例配置**，在 `src/constants.ts` 中可替换为本专业真实要求；页面显著声明。

## 4. 持久化设计（localStorage）

- 选课记录：`course-atlas:selected:v2` → `SelectedCourse[]`（含全部学期，按 termId 分区统计）
- 当前学期：`course-atlas:term:v1` → 学期 id（默认 2026-2027-1）
- 写入时机：加入 / 移除 / 改学分 / 清空后立即写入；启动时读取，解析失败静默降级
- v1 → v2 键名升级：结构变化（新增 termId、credit、评审数据），旧键不再读取

## 5. 状态设计（Pinia）

| Store | 状态 | 派生 | 动作 |
| --- | --- | --- | --- |
| term | 当前学期 id | 当前学期对象、历史学期列表 | setTerm |
| courses | 学期数据缓存、加载状态、评价缓存、筛选条件、排序、页码 | 单位列表、过滤/排序/分页结果、评价数/评价列表 | loadTerm（懒加载+缓存）、reloadTerm、各筛选 setter、reset |
| planner | 全部学期的选课记录 | 按学期分组、学期统计（门数/已录/待补/超限）、全部已录学分、分类学分、待补清单、学期内冲突对 | addCourse（查重+冲突）、addCustomCourse、setCredit、removeCourse、clearTerm |

算法为纯函数（`utils/conflict.ts`、`utils/credit.ts`），Store 只做编排与持久化，便于单测与答辩讲解。
