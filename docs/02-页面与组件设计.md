# 02 · 页面与组件设计

> 版本 v1.0 ｜ 2026-11-26 ｜ 对应阶段：需求与原型

## 1. 信息架构与路由

```
/ (重定向)
├── /courses     课程库        CourseListView
├── /timetable   模拟课表      TimetableView
├── /planner     学分规划      PlannerView
└── /custom      自定义课程    CustomCourseView
```

路由使用懒加载（`() => import(...)`），切换页面时按需加载代码；`router.afterEach` 统一设置 `document.title`。

## 2. 页面布局

### 全局骨架（App.vue）

- **顶部导航**（sticky）：Logo + 四个页面入口 + "已选 X 学分 / 156" 摘要徽章（点击跳转规划页）
- **内容区**：`max-width: 1200px` 居中
- **底部**：页脚（数据蓝本来源链接）
- **移动端（≤768px）**：顶部导航链接隐藏，改为底部固定标签栏（图标 + 文字）

### 课程库页

筛选栏（关键词 / 学院 / 类别 / 排序 / 重置）→ 课程卡片网格（自适应列数）→ 分页条 → 详情弹窗（Teleport 挂载，Esc / 遮罩点击关闭）。

### 模拟课表页

统计卡片行（已选门数 / 总学分 / 冲突数 / 前置提醒数）→ 左：课表网格（或移动端列表）右：已选课程面板 → 冲突警示条。

### 学分规划页

总学分渐变卡片（大数字 + 差距提示）→ 六类要求进度卡片（2 列）→ 完成横幅（全部达标时）→ 左列：前置提醒 + 学期分布；右列：已选明细。

### 自定义课程页

说明横幅 → 分组表单（基本信息 / 课程属性 / 上课时间）→ 全局业务校验错误区 → 提交与重置。

## 3. 组件清单与职责

### common（通用）

| 组件 | 职责 |
| --- | --- |
| AppIcon | 内联 SVG 图标库（stroke 风格，无第三方图标依赖） |
| BaseTag | 课程类别彩色标签（由 constants 的 CATEGORY_STYLE 驱动） |
| ProgressBar | 进度条（支持超限警示色） |
| PaginationBar | 页码窗口分页条（最多 5 个页码） |
| EmptyState | 空状态占位（图标 + 标题 + 提示 + 插槽操作） |
| ToastList | 全局 Toast（成功 / 警告 / 错误 / 信息） |

### courses（课程库）

| 组件 | 职责 |
| --- | --- |
| CourseFilters | 搜索框、学院 / 类别多选 chips、排序、重置；筛选条件双向绑定 store |
| CourseCard | 单门课程卡片：标签、时间预览、前置提示、"加入模拟课表"按钮 |
| CourseDetailModal | 详情弹窗：时间 / 前置满足状态 / 学期学分占用 / 加入操作 |

### timetable（课表）

| 组件 | 职责 |
| --- | --- |
| TimetableGrid | 周课表网格：表头 + 时间轴 + 课程块绝对定位；重叠块按连通分量分配泳道并排展示 |
| TimetableListView | 移动端按天分组列表视图 |
| SelectedCourseList | 已选课程面板：排序展示、移除、自定义课程标记、清空 |

### planner（规划）

| 组件 | 职责 |
| --- | --- |
| RequirementPanel | 总学分卡片 + 六类要求进度 |
| PrereqNotice | 前置课程缺失提醒（跳转课程库补选） |
| SemesterLoadPanel | 8 学期学分分布与上限预警 |
| CategoryBreakdown | 按类别分组的已选课程明细 |

### custom（自定义课程）

| 组件 | 职责 |
| --- | --- |
| CustomCourseForm | 受控表单：字段校验（touched + submitted 双重门控）、跨字段校验、业务校验（冲突 / 学分上限）、提交后重置并跳转 |

## 4. 响应式策略

| 断点 | 变化 |
| --- | --- |
| ≤1100px | 课表页 / 规划页双栏布局改为单栏堆叠 |
| ≤768px | 顶部导航 → 底部标签栏；课表网格 → 按天列表；统计卡片 4 列 → 2 列；表单双列 → 单列；页面标题缩小 |

课表网格本身在容器内横向滚动（`overflow-x: auto`），保证小屏平板场景可横向查看。
