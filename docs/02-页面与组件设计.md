# 02 · 页面与组件设计

> 版本 v2.0 ｜ 2026-11-26 ｜ 对应阶段：核心功能开发（学期切换与真实数据接入后修订）

## 1. 信息架构与路由

```
/ (重定向到 /courses)
├── /courses     课程库        CoursesView
├── /timetable   模拟课表      TimetableView
├── /planner     学分规划      PlannerView
└── /custom      自定义课程    CustomCourseView
```

- 路由懒加载；`router.afterEach` 统一设置 `document.title`。
- 学期不是路由参数而是全局状态（`termStore`），切换学期时课程库、课表、统计同步切换，避免深链接与数据加载重复。

## 2. 页面布局

### 全局骨架（App.vue）

- **顶部导航**（sticky）：Logo（南开紫）+ 四个页面入口 + **学期切换器**（学年×三学期面板，见 TermSwitcher）+ 本学期学分摘要（门数/已录学分/待补，点击进入规划）；导航永不换行，窄屏自动收缩（≤1280 隐藏副标题，≤1080 学分徽章简写）
- 内容区 `max-width: 1240px`；页脚列出数据来源链接
- **移动端（≤768px）**：导航链接收起，改底部标签栏；学期切换器保留在头部

### 课程库页

筛选栏（搜索 / 开课单位下拉 / 类别 chips / 通识模块下拉 / 排序 / 重置）→ 数据状态区（骨架屏 / 错误重试 / 卡片网格）→ 分页 → 详情弹窗。

### 模拟课表页

统计卡（已选门数 / 已录学分 / 待补学分 / 冲突数）→ 左：7 天 × 14 节课表（横向滚动）或移动端列表，右：已选课程面板（每门课含学分输入框）。

### 学分规划页

示例培养方案进度卡（总学分渐变卡 + 4 类进度 + 示例配置声明 + 待补提示）→ 左列：当前学期 / 历史学期记录卡（门数、已录学分、待补、课程清单可展开）→ 右列：全部学期按类别明细。

### 自定义课程页

说明横幅（提交到当前学期）→ 分组表单（基本信息 / 课程属性 / 上课时间）→ 业务校验错误区 → 提交与重置。

## 3. 组件清单与职责

### common（通用）

| 组件 | 职责 |
| --- | --- |
| AppIcon | 内联 SVG 图标库（stroke 风格，无第三方依赖） |
| BaseTag | 课程类别彩色标签（由 CATEGORY_STYLE 驱动） |
| ProgressBar | 进度条（支持超限警示色） |
| PaginationBar | 页码窗口分页条 |
| EmptyState | 空状态占位 |
| ToastList | 全局 Toast（成功/警告/错误/信息） |
| TermSwitcher | 学期选择面板：学年网格（2020-2021 起连续）+ 三学期列表（秋冬/春夏/暑假小学期），标注当前学期与数据可用性 |

### courses（课程库）

| 组件 | 职责 |
| --- | --- |
| CourseFilters | 搜索、开课单位、类别、通识模块、排序、重置 |
| CourseCard | 教学班卡片：类别/细类/班次、教师、时间、地点、名额、评价数、"加入课表" |
| CourseDetailModal | 详情弹窗：全部字段 + 学分说明 + 学生评价列表 + 加入 |

### timetable（课表）

| 组件 | 职责 |
| --- | --- |
| TimetableGrid | 7 天 × 14 节网格，课程块绝对定位；重叠按连通分量分泳道并排 |
| TimetableListView | 移动端按天分组列表（含"不排固定节次"分组） |
| SelectedCourseList | 已选面板：学分输入、移除、清空本学期、超上限提示 |

### planner（规划）

| 组件 | 职责 |
| --- | --- |
| RequirementPanel | 示例培养方案进度（总计 + 4 类 + 声明 + 待补提示） |
| TermOverview | 单个学期记录卡（当前/历史样式区分、课程清单展开、待补跳转） |
| CategoryBreakdown | 全部学期按类别明细（学期标、教师、学分/待补） |

### custom（自定义课程）

| 组件 | 职责 |
| --- | --- |
| CustomCourseForm | 受控表单：字段/跨字段校验（touched + submitted 门控、输入即消错）、冲突检测、提交后跳转 |

## 4. 响应式策略

| 断点 | 变化 |
| --- | --- |
| ≤1100px | 课表页 / 规划页双栏改单栏 |
| ≤768px | 顶部导航 → 底部标签栏；课表网格 → 按天列表；统计卡 4 列 → 2 列；表单双列 → 单列；课程卡单列 |

课表网格最小宽度 900px，容器内横向滚动；移动端直接切换为列表视图（不是缩放网格）。
