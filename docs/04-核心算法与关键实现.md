# 04 · 核心算法与关键实现

> 版本 v2.0 ｜ 2026-11-26 ｜ 对应阶段：核心功能开发（真实排课数据接入后修订）

## 1. 时间冲突检测（src/utils/conflict.ts）

### 判定规则

两门课冲突，当且仅当存在一对时间段满足：

1. **同一天**（1-7，含周末）；
2. **节次区间重叠**：`a.start <= b.end && b.start <= a.end`（闭区间，节次 1-14）；
3. **周次有交集**：两段周次数组存在公共周（真实数据中周次是 1-18 的具体列表，单双周自然是非连续数组）。

```ts
export function slotsConflict(a: CourseSlot, b: CourseSlot): boolean {
  return a.day === b.day && periodsOverlap(a.start, a.end, b.start, b.end) && weeksOverlap(a.weeks, b.weeks)
}
```

- 一门课可能有多个时间段；两门课两两配对检查。
- 加入课表前对新课程与**同一学期**已选课程做 `findConflict`，命中即拦截并返回冲突课程名。
- 真实数据带来的规则差异：周次不再统一为 1-16（最常见 1-17，也有 1-9、单周、17 周单周等），单双周课程不会误判冲突。
- 复杂度：每门课时间复杂度 O(n·m²)，n 为已选课数（~30），m 为时间段数（≤5），毫秒级。

## 2. 课表重叠块的泳道布局（TimetableGrid.vue）

1. 按天分组，块按 `起始节次` 排序；
2. **切分连通分量**：与当前分量任一块 `end >= 下一块 start` 则并入（传递重叠）；
3. **贪心分配泳道**：每块放入第一条"最后占用结束节次 < 本块 start"的泳道；泳道数即分量宽度；
4. 渲染：`left = (day-1)×(100/7) + lane×(100/7/lanes)`，`top = (start-1)×42px`，高度 = 节数×42px。

网格为 7 天 × 14 节，容器横向滚动；移动端整体切换为按天列表视图。

## 3. 学分统计与录入（src/utils/credit.ts）

- `sumEnteredCredits`：只累加已录入学分（`credit !== null`），`round1` 规避浮点误差；`countPendingCredits` 统计待补门数。
- `creditsByCategory`：按 5 大类汇总已录学分，作为培养方案进度条数据源。
- 录入规则：0.5-20 学分、0.5 步进；非法输入回退原值；清空输入即恢复"待补"。
- 学期上限（示例 30 学分）：已录学分超出时在已选面板和课表统计卡给出警示（不阻断，因学分本身是后录入的）。

## 4. 学期隔离与历史记录

- 选课记录以 `termId` 为主键分区（`SelectedCourse.termId`），冲突检测、统计、课表渲染都只针对当前学期。
- 学期切换只改变 `termStore.currentTermId`：课程库按学期懒加载对应数据；课表与统计即时切换；历史学期的记录原样保留（只读语义由 UI 体现：无"去课程库选课"入口，但可查看与补录学分）。
- 持久化键 `course-atlas:selected:v2` 存全部学期记录，切换/刷新都不丢。

## 5. 异步数据加载与状态机

课程库 store 对每个学期维护 `idle → loading → ready | error` 状态：

- `loadTerm(termId)` 幂等（已加载/加载中直接返回），成功进入缓存 `caches[termId]`；
- 失败记录错误信息并展示"重新加载"按钮（`reloadTerm` 清缓存后重试）；
- 首次进入显示 6 张骨架卡，避免空屏跳动。

## 6. 表单校验（CustomCourseForm.vue）

- **字段级**：名称 2-30 字、开课单位/教师必填、学分 0.5-20 且一位小数、星期/节次/周次必填；
- **跨字段**：结束节次 ≥ 起始节次、结束周 ≥ 起始周；
- **展示门控**：错误在 `touched || submitted` 时展示；**输入时实时清除已修正字段的错误**，避免错误提示突然消失导致按钮位移、点击落空（冒烟测试曾暴露的真实问题）；
- **业务级**：校验通过后做时间冲突检测，失败写入全局错误区并中断提交。
