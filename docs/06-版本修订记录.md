# 06 · 版本修订记录

## v2.0（2026-11-26）· 接入南开真实数据、学期切换与课程评价

**背景**：v1 使用长沙理工培养方案蓝本的 79 门模拟课程，属于演示态；团队成员补充了南开大学教务部公开选课手册与枝上选课攻略数据，要求切换到真实数据，并补齐"学期切换 / 历史学期查询"能力（v1 的"学期学分分布"在单学期数据下会退化），主题色改为南开紫。

### 变更清单

| 类别 | v1 | v2 | 原因 |
| --- | --- | --- | --- |
| 数据 | 79 门模拟课程（长沙理工蓝本，时间/教师虚构） | 2026 秋 4876 + 2025 春 4525 个真实教学班（教务部选课手册），教师/时间/教室/名额均为真实排课 | 提升真实性与答辩说服力 |
| 评价 | 无 | 枝上攻略 644 条学生评价，按课程名匹配（406 条命中） | 取代虚构的"前置课程"功能 |
| 学期 | 单一学期数据 | 学期切换器：2026-2027-1（当前）/ 2024-2025-2（历史），课程库/课表/统计按学期隔离 | 解决"到了下一学期就不可用"的问题 |
| 学分 | 课程内置学分 | 手册无学分 → 用户按培养方案录入，区分已录/待补 | 不虚构数据 |
| 培养方案 | 长沙理工 6 类 156 学分 | 南开 5 类示例配置（138 学分，页面声明"示例"） | 南开未公开培养方案 |
| 前置课程 | 有（模拟数据） | 移除 | 真实数据无此字段 |
| 周课表 | 5 天 × 12 节 | 7 天 × 14 节（含周末，符合南开排课） | 真实数据包含周六日与 13-14 节 |
| 主题 | 靛蓝 #4c6ef5 | 南开紫 #842468（教务部官方标识实取样） | 团队要求 |
| 数据加载 | 同步 import | 按学期 fetch + 骨架屏 + 错误重试 | 单学期数据 1.6MB，需懒加载 |
| 冒烟测试 | 20 条断言 | 34 条断言（新增学期切换、评价、学分录入、冲突精确定位） | 覆盖新功能 |

### 验证（均已核实）

- `npm run build`（vue-tsc strict + vite build）通过；ESLint 0 问题。
- `npm run smoke` 34/34 通过（含真实数据条数断言 4876/4525）。
- 数据管线：`export_app_data.py` 导出后结构自检通过；评价覆盖校验 592 个课程名中 361 个命中 2026 秋课程。

### 已知遗留

- 学分缺失属公开资料限制（见 docs/05），需用户录入；
- 培养方案为示例配置；
- 2026 春手册官方未发布，历史学期目前只有 2025 春。
