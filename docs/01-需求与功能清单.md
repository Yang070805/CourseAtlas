# 01 · 需求与功能清单

> 版本 v2.0 ｜ 2026-11-26 ｜ 对应阶段：核心功能开发（接入南开真实数据后修订）
> v1 基于模拟课程库，v2 改为南开大学教务部公开选课手册的真实数据，并新增学期切换与课程评价。修订记录见 docs/06。

## 1. 项目定位

**一句话**：把"选课"变成一次可预演的决策——用真实排课数据模拟课表、拦截时间冲突、参考学生评价、按培养方案规划学分，并保留历史学期记录。

- 项目名称：CourseAtlas · 南开选课导航
- 方向：Web（Vue 3 工程）
- 目标用户：南开大学等高校在校本科生（每学期需要自主选课的低年级学生为主）

## 2. 用户痛点与场景

| 痛点 | 现状 | 本项目解法 |
| --- | --- | --- |
| 选课时间冲突 | 教务系统仅在下单时报错，试错成本高 | 加入模拟课表时即时拦截并指明冲突课程 |
| 课程质量不明 | 只有课名和教师，选课像开盲盒 | 详情页展示枝上攻略的真实学生评价（评分制/点名/给分/任务/考核） |
| 学分进度模糊 | 学分要自己对着培养方案手算 | 录入课程学分后自动按类别汇总、算毕业差距 |
| 学期更替后记录丢失 | 教务系统不保留个人选课历史视图 | 学期切换：当前学期可选课，历史学期记录永久保留 |
| 学期学分失衡 | 不知道一学期选了多少学分 | 学期学分上限提示 + 已录/待补学分统计 |

## 4. 与课程最低要求的对照

| 课程最低要求 | 本项目实现 |
| --- | --- |
| 至少 3 个页面或视图 | 4 个路由页面（课程库 / 课表 / 规划 / 自定义课程） |
| 至少 5 个有意义的组件 | 16 个组件（见 docs/02） |
| Vue Router 页面切换 | 4 条懒加载路由 + 通配重定向 + 路由级标题 |
| 至少一个表单和表单验证 | 自定义课程表单（10+ 字段校验 + 跨字段 + 业务校验） |
| 至少一个列表数据处理功能 | 课程库（4876 条真实数据）：搜索/筛选/排序/分页四项全含 |
| 搜索、筛选、排序、分页至少两项 | 四项全部实现 |
| 至少一次共享状态管理 | Pinia：term（学期）、courses（异步数据与筛选）、planner（选课与学分） |
| 数据持久化或 Mock 数据 | 真实公开数据静态化 + localStorage 持久化（按学期分键） |
| 适配桌面端和手机端 | 断点 768px：导航形态、课表视图、双栏布局三处切换 |

## 5. 范围外（本期不做）

- 教务接口实时对接、登录与多用户
- 课程余量/抢课提醒、退补选流程模拟
- 精确的专业培养方案（南开未公开，本项目用示例配置 + 用户录入学分兜底）
