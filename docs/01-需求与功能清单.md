# 01 · 需求与功能清单

> 版本 v1.0 ｜ 2026-11-26 ｜ 对应阶段：选题与需求

## 1. 项目定位

**一句话**：填补学校教务系统"只管抢课、不管规划"的空白，帮学生在选课周前完成模拟排课、冲突检测与学分路径规划。

- 项目名称：CourseAtlas · 选课导航（高校模拟排课与学分路径规划器）
- 方向：Web（Vue 3 工程）
- 目标用户：软件工程等工科专业在校本科生（大一至大三选课主力人群）

## 2. 用户痛点与场景

| 痛点 | 现状 | 本项目解法 |
| --- | --- | --- |
| 选课时间冲突 | 教务系统仅在下单时报错，试错成本高 | 加入模拟课表时即时拦截并指明冲突课程 |
| 前置课程漏修 | 只有培养方案 PDF，需要人工对照 | 加入课程时提醒 + 规划页集中列出缺失前置 |
| 学分进度模糊 | 不知道离毕业还差几分 | 按培养方案分类展示进度条与差距 |
| 学期学分失衡 | 某学期选超 / 选少 | 学期学分上限校验 + 每学期分布视图 |

## 4. 与课程最低要求的对照

| 课程最低要求 | 本项目实现 |
| --- | --- |
| 至少 3 个页面或视图 | 4 个路由页面（课程库 / 课表 / 规划 / 自定义课程） |
| 至少 5 个有意义的组件 | 15+ 个组件（见 docs/02） |
| Vue Router 页面切换 | 4 条懒加载路由 + 通配重定向 + 路由级标题 |
| 至少一个表单和表单验证 | 自定义课程表单（10 个字段校验 + 业务校验） |
| 至少一个列表数据处理功能 | 课程库列表（搜索 / 筛选 / 排序 / 分页四项全含） |
| 搜索、筛选、排序、分页至少两项 | 四项全部实现 |
| 至少一次共享状态管理 | Pinia：courses（课程库与筛选）、planner（已选课程与统计） |
| 数据持久化或 Mock 数据 | 79 门课程 Mock + localStorage 持久化 |
| 适配桌面端和手机端 | 断点 768px：导航形态、课表视图、布局栅格三处切换 |
